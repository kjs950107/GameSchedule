## 1. 처음 켰을 때

- 바탕화면 **오른쪽 위**에 위젯 5개가 나란히 떠요: **일일 숙제 · 주간 숙제 · 주기 컨텐츠 · 이벤트·목표 · 픽업**
- 위젯은 바탕화면에 붙어 있어서 **다른 프로그램 위로 올라오지 않아요.** Win+D(바탕화면 보기)를 눌러도 사라지지 않아요.
- 작업표시줄 오른쪽 아래(시계 옆, 안 보이면 `^` 안쪽)에 **트레이 아이콘**이 생겨요.
  - 한 번 클릭: 위젯을 잠깐 맨 앞으로
  - 두 번 클릭: 설정 창
  - 오른쪽 클릭: 메뉴 (위젯 켜기/끄기, 등록, 종료 등)
- **PC를 켤 때마다 자동으로 실행**하려면 트레이 메뉴 → **윈도우 시작 시 실행**을 체크하세요.

> 위젯 위쪽 제목 부분을 끌면 옮길 수 있고, 오른쪽 아래 모서리로 크기를 바꿔요. 위치는 자동으로 기억돼요.

## 2. 내 게임으로 바꾸기

위젯의 **⚙** 버튼 (또는 트레이 아이콘 두 번 클릭) → **게임 / 숙제** 탭

처음엔 예시 게임들이 들어 있어요. 안 하는 게임은 고르고 **삭제**, 하는 게임은 **추가**하세요.

**게임 정보**
- **분류**
  - 모바일 게임: 계정 하나 (니케, 스타레일 같은 게임)
  - RPG: 캐릭터 여러 개 (로스트아크, 마비노기 영웅전 같은 게임)
  - 숙제 없는 게임: 위젯에는 안 나오고 플레이 시간만 기록 (롤, 하스스톤 같은 게임)
- **초기화 시각**: 그 게임의 일일 초기화 시각 (예: `06:00`). 이 시각이 지나면 체크가 풀려요.
- **주간 초기화 요일**: 주간 숙제가 풀리는 요일

**캐릭터** (RPG만) — 캐릭터 이름을 추가하세요. 위젯에서 캐릭터가 열(가로)로 나와요.

**숙제** — 추가 후 아래 **숙제 상세**에서:
- **초기화 규칙**: 매일 / 매주 / 특정 요일에만 (예: 화·금에만 하는 컨텐츠) / 매월 N일
- **표시 안 할 요일**: 그 요일엔 위젯에서 숨김 (예: 수요일엔 없는 컨텐츠)
- **적용 범위** (RPG): 원정대 공통(체크 1개) / 캐릭터마다
- **하는 캐릭터**: 일부 캐릭터만 하는 숙제면 나머지 체크 해제
- **캐릭터별 이름**: 같은 칸인데 캐릭터마다 다른 이름 (예: '레이드 1' 칸을 캐릭터마다 다른 레이드로)

> 시간은 모두 **게임 기준 날짜**예요. 초기화가 06:00인 게임은 새벽 3시를 아직 "전날"로 봐요.

## 3. 숙제 체크하기

- 위젯에서 체크박스를 누르면 끝. 다시 누르면 취소돼요.
- 게임의 숙제를 다 끝내면 그 게임 카드가 **흐려지고 접혀서 아래로** 내려가요.
- 게임 이름을 누르면 카드를 접었다 폈다 할 수 있어요.
- 초기화 시각이 지나면 체크가 자동으로 풀려요. **PC를 꺼 둔 사이에 초기화가 지나가도** 정확하게 풀려요.

## 4. 색깔 표시의 뜻

| 표시 | 뜻 |
|---|---|
| 🟧 주황 테두리 · 주황 글씨 | 곧 초기화되는데 아직 안 한 숙제 (주간·월간은 초기화 전날, 특정 요일 숙제는 그날, 주기 컨텐츠는 마감 7일 전부터) |
| 🟥 빨간 테두리 | 이벤트 마감이 7일 이하 남음 (1일 이하면 더 진하게) |
| 회색 [놓침] | 기간이 끝났는데 못 한 이벤트 → **확인 ✕** 를 누르면 지워져요 |
| 흐리게 | 다 끝냄 |

## 5. 이벤트 · 목표

**이벤트·목표 위젯의 ＋** (또는 설정 → **이벤트 / 목표** 탭)

- **기한 있는 이벤트** (모바일 게임만): 게임과 마감일만 고르면 돼요. 이름은 선택.
  마감일 다음 날 게임 초기화 시각에 끝나요. 끝나면 완료한 건 자동 삭제, 못 한 건 [놓침]으로 남아요.
- **무기한 목표** (모든 게임): "메인스토리 깨기"처럼 기한 없는 목표. 완료하면 다음 초기화 때 사라져요.

## 6. 주기 컨텐츠 (몇 주마다)

4주, 6주처럼 **몇 주마다 돌아오는 컨텐츠**용이에요. 일일·주간 숙제와 따로 관리돼요.

**주기 컨텐츠 위젯의 ＋** (또는 설정 → **주기 컨텐츠** 탭 → **＋ 새로 등록**)

1. 게임, 이름을 고르고
2. **이번 회차**: "오늘부터 ○월 ○일까지" — 지금 회차가 끝나는 날
3. **다음부터**: "○주마다 ○요일까지" — 그 뒤로 계속 반복

창 아래에 앞으로의 마감일이 미리 보여요. 마감 **7일 전부터 주황색**으로 바뀌고 "D-5 · 12/7(월)까지"처럼 표시돼요. 수정은 탭에서 두 번 클릭.

## 7. 픽업

게임마다 지금 어떤 픽업(가챠)을 하는지 기간만 적어 두는 곳이에요. 체크나 경고는 없어요.

**픽업 위젯의 ＋** (또는 설정 → **픽업** 탭) → 게임, 픽업 이름, 기간 → **등록**

위젯에 **진행 중 / 예정**으로 나오고, 마지막 날이 지나면 자동으로 지워져요.

## 8. 위젯 합치기 / 나누기 · 꾸미기

설정 → **위젯** 탭

**위젯 배치** — 칸 5개 = 위젯 창 5개
- 이름표(예: `일일 숙제`)를 **다른 칸으로 끌어다 놓으면 합쳐져요** → 넓은 위젯 하나에 나란히
- 칸이 비면 그 창은 없어져요 (창 4개, 3개…)
- **빈 칸으로 끌어 놓으면** 다시 따로 떨어져요
- 이름표 **오른쪽 클릭**으로도 옮길 수 있어요
- **처음 상태로** 버튼: 다시 5개 따로

**위젯별 설정** (위젯마다 따로)
- **색 테마**: 다크 / 라이트 / 글래스
- **배경 이미지**: 원하는 그림을 위젯 배경으로. 글씨가 잘 안 보이면 **배경 가림 정도**를 올리세요
- **항상 위**: 켜면 게임 화면 위에도 떠 있어요 (위젯 제목줄의 체크로도 가능)

**표시** — 투명도, 위치 잠금, 끝낸 숙제 아래로 정렬

## 9. 플레이 시간 통계

설정 → **통계** 탭에서 PC 켠 뒤 첫 체크까지 걸린 시간, 게임별 플레이 시간, 요일별 시간, 숙제 순서 등을 볼 수 있어요.

플레이 시간을 재려면 **게임 실행 파일을 등록**해야 해요:
1. 게임을 켜 둔 상태에서
2. 설정 → 게임 / 숙제 → 그 게임 → **실행 파일** → **실행 중인 프로그램에서 고르기**
3. 런처 말고 **실제 게임** exe를 고르세요

## 10. 친구와 공유하기

이벤트·목표, 주기 컨텐츠, 픽업은 각 탭에서 골라서 주고받을 수 있어요.

- **보내는 사람**: 탭 아래 **내보내기…** → 보낼 항목 체크 → 파일로 저장 → 파일 전달
- **받는 사람**: 같은 탭 **가져오기…** → 파일 선택 → 게임 연결 확인 → **추가**
  - 게임 이름이 다르면 (예: `니케` ↔ `승리의 여신: 니케`) 빨간 글씨 옆에서 내 게임을 골라 주세요
  - 지금 데이터는 그대로 두고 **추가만** 돼요. 완료 체크는 같이 가지 않아요
  - 이미 있거나 끝난 항목은 자동으로 건너뛰어요

## 11. 자주 묻는 것

**위젯이 안 보여요** — 트레이 아이콘을 한 번 클릭하세요. 그래도 없으면 트레이 메뉴에서 위젯이 켜져 있는지 확인하거나, 설정 → 위젯 → **위젯을 주 모니터에 나란히 놓기**.

**모니터를 바꿨더니 위젯이 사라졌어요** — 화면 밖으로 나간 위젯은 자동으로 주 모니터로 돌아와요. 안 되면 위 방법으로.

**다른 PC로 옮기고 싶어요** — 설정 → 위젯 → **백업 내보내기** → 새 PC에서 **백업 불러오기**. (통계 기록과 배경 이미지는 빠져요)

**데이터는 어디 저장돼요?** — `%AppData%\GameHomework` 폴더 (설정 → 위젯 → 데이터 폴더 열기). 인터넷으로 보내지 않아요.

**처음 실행할 때 파란 경고창이 떠요** — 코드 서명을 하지 않은 개인 배포 프로그램이라 그래요. **추가 정보 → 실행**을 누르세요.

**완전히 지우고 싶어요** — 트레이 메뉴에서 **윈도우 시작 시 실행**을 끄고 → **종료** → exe 파일과 `%AppData%\GameHomework` 폴더를 지우면 끝이에요.

**문제가 생겼어요** — `%AppData%\GameHomework\error.log` 파일과 함께 [Issues](https://github.com/kjs950107/GameSchedule/issues)에 남겨 주세요.
