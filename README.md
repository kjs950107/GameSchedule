# GameSchedule — 게임 숙제 관리

[![build](https://github.com/kjs950107/GameSchedule/actions/workflows/build.yml/badge.svg)](https://github.com/kjs950107/GameSchedule/actions/workflows/build.yml)

바탕화면에 스티커 메모처럼 붙어 있는 게임 숙제 체크리스트입니다. (Windows 10/11, C# WPF .NET 8)

위젯 종류는 5가지 — **일일 숙제** / **주간 숙제**(매주·특정 요일·매월) / **주기 컨텐츠**(N주마다) / **이벤트 · 목표** / **픽업**.

**위젯 배치** (설정 → 위젯 탭): 칸 5개 = 위젯 창 5개. 처음엔 칸마다 하나씩 들어 있고, 이름표를 다른 칸으로 **끌어다 놓으면 합쳐져서** 넓은 위젯 하나에 나란히 나옵니다. 칸이 비면 그 창은 없어지고(창 4개, 3개…), 빈 칸으로 끌어 놓으면 다시 따로 떨어져요. 같은 칸 안에서 끌면 열 순서가 바뀌고, 이름표 오른쪽 클릭 메뉴로도 옮길 수 있어요. 위치·테마·항상 위는 칸(창)마다 따로 기억돼요. (예전 '합쳐서 보기' 설정은 처음 실행할 때 자동으로 칸으로 옮겨져요)

## 다운로드 / 설치

1. [Releases](https://github.com/kjs950107/GameSchedule/releases)에서 `GameHomework.exe`를 받습니다. (.NET 설치 필요 없음)
2. 원하는 폴더에 두고 실행 → 트레이 메뉴에서 **윈도우 시작 시 실행**을 체크하면 PC를 켤 때마다 자동으로 떠요.
3. 처음 실행할 때 **"Windows의 PC 보호"** 파란 창이 뜨면 **추가 정보 → 실행**을 누르세요.
   코드 서명(유료 인증서)을 하지 않은 개인 배포 프로그램이라 뜨는 경고예요.

### 안전한지 확인하는 방법

- Releases의 exe는 내 PC가 아니라 **GitHub Actions가 이 저장소의 공개 소스로 직접 빌드**한 것입니다. 각 릴리스에 빌드 기록 링크가 있어요.
- 릴리스에 적힌 **SHA-256** 값과 받은 파일이 같은지 PowerShell에서 확인할 수 있어요: `Get-FileHash GameHomework.exe`
- 소스를 직접 받아서 빌드해 써도 됩니다 (아래).
- 인터넷에 접속하지 않고, 데이터는 내 PC(`%AppData%\GameHomework`)에만 저장돼요. 플레이 시간 측정은 실행 중인 프로그램 이름만 확인합니다. '윈도우 시작 시 실행'을 켜면 레지스트리 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`에 등록되고, 끄면 지워져요.

## 소스로 직접 빌드

1. [.NET 8 SDK (x64)](https://dotnet.microsoft.com/download/dotnet/8.0) 설치
2. `build.bat` 더블클릭 → 테스트 실행 후 `publish\GameHomework.exe` 생성
3. exe를 원하는 폴더로 옮겨 실행 → 트레이 메뉴에서 **윈도우 시작 시 실행** 체크

Visual Studio 2022에서 `GameHomework.sln`을 열어 F5로 실행해도 됩니다.

## 사용법

| 동작 | 방법 |
|---|---|
| 위젯 이동 | 위쪽 제목 부분을 끌기 (모니터 2대 어디든 가능, 위젯마다 위치 자동 저장) |
| 위젯 찾기 | 작업표시줄 버튼 클릭 → 잠깐 맨 앞으로, 다른 곳 클릭(또는 버튼 다시 클릭) → 바탕화면으로. 트레이 아이콘 클릭 시 전부 |
| 위젯 켜기/끄기 | 트레이 메뉴 또는 설정 → 위젯 탭의 칸마다 '보이기' |
| 위젯 합치기/나누기 | 설정 → 위젯 탭에서 이름표를 다른 칸으로 끌기 (트레이 메뉴 → 위젯 배치 바꾸기) |
| 항상 위 | 위젯 제목줄의 **항상 위** 체크 (설정 → 위젯 탭, 트레이 메뉴에서도 가능). 켜면 다른 창 위에 계속 떠 있음 |
| 크기 조절 | 오른쪽 아래 모서리 끌기 |
| 게임 카드 접기/펼치기 | 게임 이름 클릭 (다 끝낸 게임은 자동으로 접히고 흐려짐) |
| 이벤트 등록 | ＋ 버튼 → "이벤트 등록" / "무기한 목표 등록" / (합친 위젯) "숙제 추가" 중 선택 |
| 주기 컨텐츠 | 주기 컨텐츠 위젯 ＋, 트레이 메뉴, 또는 설정 → **주기 컨텐츠** 탭. 새 창에서 "오늘부터 ○월 ○일까지" + "다음부터 N주마다 ○요일까지" |
| 픽업 | 픽업 위젯 ＋, 트레이 메뉴, 또는 설정 → **픽업** 탭. 게임 · 픽업 이름 · 기간만 입력 |
| 공유 (내보내기 / 가져오기) | 설정 → 이벤트·목표 / 주기 컨텐츠 / 픽업 탭의 **내보내기…** → 보낼 항목 체크 → 파일 저장. 받는 사람은 같은 탭의 **가져오기…** → 게임 연결 확인 → 체크한 항목만 **추가** (지금 데이터는 그대로, 완료 체크는 안 넘어감, 이미 있거나 끝난 건 건너뜀). 게임은 이름으로 자동 연결되고, 이름이 다르면 직접 골라 연결 |
| 무기한 목표 | ＋ 버튼 → "무기한 목표" 선택 → 게임, 이름 입력 (예: 메인스토리 깨기, 모든 게임 가능) |
| 설정 | 위젯의 ⚙ 버튼, 또는 트레이 아이콘 더블클릭 |
| 숨기기 / 종료 | 트레이 아이콘 오른쪽 클릭 |

## 동작 방식

- **바탕화면 고정**: 다른 프로그램 위로 올라오지 않고, Win+D를 눌러도 사라지지 않음. 클릭해도 게임 창의 포커스를 뺏지 않음
- **초기화**: 체크한 시각을 저장해 두고 "직전 초기화 이후에 체크했는가"로 판단 → PC를 꺼 둔 사이 초기화가 지나가도 정확
- **게임 기준 날짜**: 초기화 시각 이전은 전날로 취급 (로아 06:00 초기화면 새벽 3시는 전날)
- **초기화 규칙**: 매일 / 매주(게임별 주간 요일) / 특정 요일에만(예: 붕3 심연 화·금 — 그 요일 당일에만 위젯에 표시, "오늘 하는 날") / 매월 N일
- **표시 안 할 요일**: 예) 로아 카게/필보는 수요일에 숨김
- **주기 컨텐츠 (N주마다)**: 4주·6주처럼 몇 주마다 돌아오는 컨텐츠. 처음엔 이번 회차 마감일을 고르고, 그 뒤로는 N주마다 정한 요일이 마감. 마감일 다음 날 게임 초기화 시각에 새 회차 시작. 일일·주간 숙제나 이벤트와 별개로 **주기 컨텐츠 위젯**과 설정의 **주기 컨텐츠 탭**에서 따로 관리. 위젯에 D-day로 표시되고, **마감 7일 전(D-7)부터 주황 경고** + "D-5 · 12/7(월)까지". 탭에서 두 번 클릭하면 수정 (이번 회차에 한 체크는 유지)
- **픽업**: 게임별로 지금 진행 중 / 예정인 픽업과 기간 표시 (체크·알림 없음). 마지막 날(게임 기준 날짜)이 지나면 자동 삭제
- **이벤트**: 마감일까지 표시 (다음 날 게임 초기화 시각에 끝남), 7일 이하 남으면 빨간 테두리, 1일 이하면 더 진하게. 끝나면 완료한 건 **자동 삭제**, 못 끝낸 건 **[놓침]**으로 회색 표시 → [확인 ✕] 눌러서 삭제
- **특정 요일 숙제 당일 경고**: 심연(화·금)처럼 그날만 하는 숙제는 그날 안 했으면 주황 표시 + "내일 04:00까지"
- **초기화 전날 경고**: 매주·매월 숙제가 초기화 전날(게임 기준 날짜, 예: 월요일 04:00 초기화 → 일요일 04:00부터)까지 남아 있으면 카드에 주황 테두리 + "내일 04:00까지 · N개 남음", 남은 숙제는 주황 글씨
- **정렬**: 체크한 숙제와 다 끝낸 게임은 아래로, 남은 숙제가 위로 (설정 → 위젯 탭에서 끌 수 있음)
- **무기한 목표**: 기한 없이 계속 표시. 완료 체크하면 그 게임의 다음 초기화 시각까지 흐리게 보이다가 **자동 삭제** (그 전에 체크를 풀면 유지)

## 테마 · 배경 이미지 (설정 → 위젯 탭)

위젯마다 따로 정할 수 있고, "세 위젯 모두에 적용"으로 한 번에 맞출 수도 있어요.

| 테마 | 어울리는 이미지 | 글씨 |
|---|---|---|
| 다크 (기본) | 어두운 이미지 | 밝은 글씨 |
| 라이트 | 밝은 이미지 | 어두운 글씨 |
| 글래스 | 사진처럼 밝고 어두운 곳이 섞인 이미지 | 흰 글씨 + 그림자, 이미지가 가장 잘 보임 |

- **배경 가림 정도**: 테마 색을 이미지 위에 얼마나 덮을지 (0% = 이미지 그대로, 100% = 테마 색만). 글씨가 잘 안 읽히면 올리세요.
- 고른 이미지는 `%AppData%\GameHomework\backgrounds`로 복사되어서, 원본을 옮기거나 지워도 유지돼요.
- 이미지는 위젯 크기에 맞게 꽉 채워지고(잘리는 부분은 "맞춤"에서 위/가운데/아래 선택), 위젯의 투명도 설정은 그대로 적용돼요.

## 통계 (설정 → 통계 탭)

맨 위 **오늘** 칸: PC 켠 시각, 켜진 지 얼마나, 그중 실제로 게임한 시간(지금 켜져 있는 게임 포함), 게임별 시간과 "실행 중" 표시, 오늘 숙제 진행. 트레이 아이콘에 마우스를 올려도 짧게 보여요. 버전은 설정 창 제목·트레이 메뉴 맨 위에 표시돼요.

| 통계 | 기준 |
|---|---|
| PC를 켜고 첫 체크까지 | 앱 시작(자동 실행 시 = PC 켠 시각)·절전 해제 후 첫 체크 |
| 체크 사이 간격 | 체크 → 다음 체크 (앱을 다시 켜면 끊음), 실수로 체크 후 해제한 건 제외 |
| 주간 숙제를 주로 깨는 요일 | 매주·특정 요일·매월 숙제, 게임 초기화 시각 기준 요일 |
| 이벤트 마감 며칠 전에 깼는지 | 기한 이벤트만, 놓친 이벤트는 [확인 ✕]로 지울 때 기록 |
| 먼저 시작하는 게임 | 하루(새벽 4시 기준) 중 가장 먼저 실행한 게임, 숙제 없는 게임 제외 |
| 일일 숙제 하는 순서 | 게임별 그날 첫 일일 숙제 체크 순서 — 콤보로 **평균 순서** / **자주 나온 순서**(상위 5개) 선택 |
| 게임별 플레이 시간 | 켜둔 시간 / 화면 맨 앞에 있던 시간 (15초마다 확인) |
| 요일별 게임 시간 | 요일 × 게임 표 (하루 평균 / 합계 선택), 맨 윗줄은 실제로 게임한 시간 |
| 하루 평균 게임 시간 | 게임이 하나라도 켜져 있던 실제 시간 (여러 게임을 동시에 켠 시간은 한 번만) ÷ 게임한 날 수 |

- 플레이 시간은 **설정 → 게임 정보 → 실행 파일**에 게임 exe를 등록해야 측정됩니다 ("실행 중인 프로그램에서 고르기").
- **숙제 없는 게임**(분류: "숙제 없는 게임")은 위젯에 안 나오고 플레이 시간만 기록됩니다. 기본으로 하스스톤, 리그 오브 레전드가 들어 있어요.
- 기록 파일: `%AppData%\GameHomework\logs\yyyy-MM.jsonl` (월별). 통계 탭에서 CSV로 내보내기 가능.

## 폴더 구조

```
src/GameHomework/
  Core/                 초기화 계산, 데이터 모델, 저장 (UI 없음 → 테스트 가능)
  Native/DesktopPinner  바탕화면 고정 (Win32)
  WidgetWindow          위젯
  SettingsWindow        설정 창
  TrayIcon, AutoStart   트레이 / 자동 실행
tests/CoreTests/        초기화 로직 테스트 (dotnet run)
```
